# How to run Vienna!

# สอนรันภาษาไทย
1.ดาวน์โหลดซอร์สโค้ดนี้และแตกไฟล์

2.คลิกที่ไฟล์ **build-fountain.bat** 2 ครั้ง หากขึ้นแจ้งเตือนให้กด **เรียกใช้** รอ Complier จนกว่าจะขึ้นข้อความ **BUILD SUCCESS!** แล้วกดปิดโปรแกรม

3.เข้าโฟลเดอร์ **buildplate** เข้าโฟลเดอร์ย่อยชื่อ **Fountain-connector-plugin-base** แล้วคลิกที่ไฟล์ **install.bat** 2 ครั้ง รอจนกว่าจะขึ้นข้อความ **C:\Users\...>_** แล้วกดปิดโปรแกรม

4.กลับที่หน้าโฟลเดอร์หลัก ให้คลิกที่ไฟล์ **set.bat** 2 ครั้ง รอจนกว่า
