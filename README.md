# How to run Vienna!

# สอนรันภาษาไทย
1.ดาวน์โหลดซอร์สโค้ดนี้และแตกไฟล์

2.คลิกที่ไฟล์ **build-fountain.bat** 2 ครั้ง หากขึ้นแจ้งเตือนให้กด **เรียกใช้** รอ Complier จนกว่าจะขึ้นข้อความ **BUILD SUCCESS!** แล้วกดปิดโปรแกรม

3.เข้าโฟลเดอร์ **buildplate** เข้าโฟลเดอร์ย่อยชื่อ **Fountain-connector-plugin-base** แล้วคลิกที่ไฟล์ **install.bat** 2 ครั้ง รอจนกว่าจะขึ้นข้อความ **C:\Users\...>_** แล้วกดปิดโปรแกรม

4.กลับที่หน้าโฟลเดอร์หลัก ให้คลิกที่ไฟล์ **set.bat** 2 ครั้ง รอจนกว่าโปรแกรมปิดเองและไฟล์ set.bat ถูกลบ

5.รันเซิร์ฟเวอร์ Vienna ด้วยการคลิกที่ไฟล์ **run.bat** ในการใช้งานช่วงแรกอาจมีการ Complier บางอย่าง (ในหน้าต่างโปรแกรม mvnw.cmd) รอจนกว่าโปรแกรมจะทำงานเสร็จแล้วจะสามารถเล่น Minecraft Earth ได้เลย วิธีการหยุดรันให้พิมพ์ข้อความ **off** ในหน้าต่างโปรแกรม Vienna Controller
